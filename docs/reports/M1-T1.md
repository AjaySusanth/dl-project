## 3. What I implemented

Added `load_trips(config)`, which:

1. Reads `paths.raw_dir` and `data.months`.
2. Builds the expected `yellow_tripdata_YYYY-MM.parquet` path for each month.
3. Loads only pickup time, dropoff time, and pickup location columns.
4. Logs a warning for each missing configured file.
5. Concatenates available files into one DataFrame.
6. Raises a clear `FileNotFoundError` if none are available.

### File-by-file explanation

#### `src/data/ingest.py`

- **Responsibility:** Load configured raw Yellow Taxi trip records.
- **Changes:** Added the raw-column contract, path helper, and `load_trips`.
- **How it works:** Pandas reads selected Parquet columns for each available
  month. The frames are concatenated with a fresh integer index.
- **Why this design:** Reading only required columns reduces memory use and
  prevents unrelated raw fields from entering later processing.
- **Connections:** M1-T2 will consume the returned DataFrame for cleaning.

#### `.gitignore`

- **Responsibility:** Exclude generated root data and artifacts without
  excluding source packages with similar names.
- **Changes:** Anchored the `data/` and `artifacts/` patterns to the
  repository root.
- **Why this design:** The source package is named `src/data`; an unanchored
  `data/` pattern incorrectly hid it from Git.

## 4. Architecture and data flow

`data/raw/yellow_tripdata_YYYY-MM.parquet → load_trips → raw trip DataFrame`

The loader does not use `taxi_zone_lookup.csv` yet. Zone lookup membership is
part of the cleaning rules and will be applied in M1-T2.

## 5. Key technical decisions

| Decision | Reason | Alternative considered | Trade-off / consequence |
|---|---|---|---|
| Read only three required columns | Matches the architecture and reduces memory | Read all columns; not considered | Later functions cannot rely on unrelated raw fields |
| Warn and continue for missing months | Matches the task plan and allows partial smoke inputs | Fail immediately on the first missing file; not considered | A run with no available file still fails explicitly |
| Raise when no files are loaded | Prevents an empty DataFrame from looking like valid input | Return empty DataFrame; rejected | Callers receive an actionable failure |
| Use logging for missing files | Matches project code standards | Print warnings; rejected | Warning visibility depends on logging configuration |

## 6. Deep learning / data-science explanation

- **Concepts used:** Column projection and data ingestion.
- **Inputs and targets:** Each raw row represents one taxi trip. The loader
  preserves pickup timestamp, dropoff timestamp, and pickup zone ID.
- **Math or loss function:** Not applicable.
- **Training/evaluation implications:** No model sees data yet; later cleaning
  and aggregation will turn these trips into hourly counts.
- **Leakage and reproducibility safeguards:** Month selection comes from the
  configuration rather than an uncontrolled directory scan, making the input
  period explicit and reproducible.
