## 3. What I implemented

- `mae`: mean absolute pickup-count error.
- `rmse`: square root of mean squared error.
- `wape`: total absolute error divided by total absolute actual demand.
- `peak_mae`: MAE only where actual demand reaches the zone threshold.
- `coverage`: fraction of actuals inside inclusive lower and upper bounds.
- `interval_width`: mean upper minus lower bound.

All metrics validate equal shapes, non-empty finite inputs, and valid interval
ordering. WAPE rejects a zero actual denominator, and peak MAE rejects a
threshold with no matching actual values.

## 4. Learning explanation

MAE answers “how many pickups wrong on average?” RMSE emphasizes unusually
large errors. WAPE normalizes total error by demand volume, making comparisons
between busy and quiet zones more meaningful. Peak MAE focuses on high-demand
periods, where fleet decisions are most sensitive. Coverage checks whether the
P10-to-P90 interval contains the actual value, while width measures the
interval's average uncertainty size.

The model evaluator will pass P50 to the point metrics and P10/P90 to the
interval metrics, as required by the architecture.
