## 2. Pre-coding briefing

### What I planned to do

Connect M2 zone selection, split computation, train-only statistics, busy-time
calculation, and window construction into one command-line stage.

### Why this task is needed

The reusable modules now work independently, but the project needs one
repeatable pipeline command that creates the artifacts consumed by training.

### Expected files

- `scripts/build_features.py`
- `docs/reports/M2-T5.md`

## 3. What I implemented

The CLI:

1. Loads `hourly_all.parquet` and the zone lookup.
2. Selects zones using training-period demand.
3. Writes `hourly_selected.parquet`.
4. Computes and writes `splits.json`.
5. Fits and writes `zone_stats.json`.
6. Computes and writes `busy_time.parquet`.
7. Builds and writes `.npz` windows for each configured lookback.
8. Supports `--lookback L` to build one selected lookback.

Errors are logged and return exit code 1, matching the existing ingestion CLI.
