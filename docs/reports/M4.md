# M4 milestone report — LSTM and GRU quantile training

## What was completed

- Implemented mean pinball loss for multi-horizon quantile forecasts.
- Implemented the shared `QuantileRNN` with interchangeable LSTM and GRU

  data loading, and best-checkpoint saving.

## Learning summary

M4 turns the prepared windows into trainable forecasting models. The recurrent
encoder summarizes recent demand and time features, the zone embedding lets
one shared model distinguish zones, and pinball loss trains P10/P50/P90
predictions. Validation loss controls checkpoint selection; test data is not
used during training.
