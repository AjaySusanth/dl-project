## Learning summary

The fleet layer translates probabilistic demand into an operational decision.
P50 estimates expected demand, while P90 provides a safer planning level.
The difference between each required taxi count and available taxis becomes a
gap, allowing the dashboard to distinguish normal operation, risk, and an
expected shortage.

The dashboard is intentionally artifact-driven: it displays saved forecasts
and evaluation outputs but never trains a model or uses live data.
