### File-by-file explanation

#### `requirements.txt`

- **Responsibility:** Declare the reproducible Python dependency set.
- **Changes:** Added exact versions for the eight approved packages.
- **How it works:** `python -m pip install -r requirements.txt` installs the
  declared versions into the active environment.
- **Why this design:** Exact pins reduce accidental differences between
  development and validation environments.
- **Connections:** M0-T4 requires PyYAML, NumPy, and PyTorch; later stages
  require the complete stack.

## 5. Key technical decisions

| Decision | Reason | Alternative considered | Trade-off / consequence |
|---|---|---|---|
| Pin every approved dependency | Supports repeatable experiments | Unpinned minimum versions; not considered | Future upgrades require an intentional manifest change |
| Use the documented core stack only | Avoids unapproved dependencies | Add convenience packages; not considered | Some functionality must use the approved libraries |
| Require Python 3.11 for installation | Matches `AGENTS.md` and project design | Install under available Python 3.13; rejected | A Python 3.11 interpreter must be supplied or installed |
