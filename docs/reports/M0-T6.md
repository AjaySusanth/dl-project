## 5. Key technical decisions

| Decision | Reason | Alternative considered | Trade-off / consequence |
|---|---|---|---|
| Use uv commands in the setup | The user requested uv and it provides the required Python 3.11 environment | Manual system Python setup; not considered | Readers need uv installed |
| Use the environment's explicit Python executable | Avoids ambiguity about the active interpreter | Rely on shell activation; not considered | Commands are longer but deterministic |
| Document both default and smoke workflows | Supports fast validation and full experiments | Document only the full pipeline; not considered | Readers must understand that smoke metrics are not final |

## 6. Deep learning / data-science explanation

- **Concepts used:** Reproducible environments, chronological pipeline stages,
  and leakage-aware experimentation.
- **Inputs and targets:** The README identifies raw trip files as inputs and
  six-hour pickup forecasts as the eventual targets.
- **Math or loss function:** It records that the model uses P10/P50/P90 and
  that predictions are inverse-transformed and clipped before metrics.
- **Training/evaluation implications:** It states that validation controls
  early stopping and model selection while test data remains untouched.
- **Leakage and reproducibility safeguards:** It documents chronological
  splits, train-only statistics, shared LSTM/GRU protocols, and fixed seeds.
