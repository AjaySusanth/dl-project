# M3 milestone report — Baselines and evaluation harness

## What was completed

- Implemented six raw-count evaluation metrics.
- Implemented same-hour-yesterday (lag 24) and same-hour-last-week (lag 168)
  baselines.
- Implemented prediction evaluation with per-horizon, overall, and per-zone
  metrics.
- Implemented seed aggregation with mean/std results.
- Implemented validation-MAE-only application-model selection.
- Added `scripts/evaluate.py` to discover predictions, generate baseline
  artifacts, write metric JSON files, aggregate results, and select
  `app_model.json`.
- Added focused tests for metrics, baselines, evaluation schemas, aggregation,
  and selection.
